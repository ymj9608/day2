## ML Pipeline 평가

- 모델: 수치형 중앙값 대체·표준화 + 범주형 최빈값 대체·원-핫 인코딩 + 로지스틱 회귀
- 분할 전 결측치: 4,261개
- Pipeline 전처리 후 결측치: 0개
- 테스트 표본: 6,508건
- 정확도: 0.8569
- F1: 0.6762
- 저장 모델: [adult_income_pipeline.joblib](adult_income_pipeline.joblib)

정확도는 전체 정답 비율이고, F1은 상대적으로 적은 `>50K` 집단의 정밀도와 재현율을 함께 반영한다.
